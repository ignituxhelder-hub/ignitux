# Générateur Statuts — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construire la confirmation de forme juridique sur un projet et le
générateur IGINI « Statuts » (brouillon structuré des statuts, limité aux
formes à personne morale, cycle brouillon → retenu, export PDF à la
demande).

**Architecture:** Un champ `confirmed_legal_form` ajouté au module
`projects` existant (même patron que `secteur`/`visibility`). Un nouveau
module `backend/src/statuts/`, même patron que `backend/src/identite/`, qui
appelle `ClaudeService.generateStructuredOutput` (exactement comme
`FormerService`) pour produire le texte, attribué au générateur **`former`**
existant — pas un septième générateur (voir Global Constraints).

**Tech Stack:** NestJS, Prisma/Postgres, `ClaudeService` existant
(`src/igini/claude/`), `pdfkit` (nouvelle dépendance, pur JS, aucun binaire
système) pour l'export PDF à la volée. Next.js/React côté frontend, mêmes
conventions que `frontend/src/app/projects/[id]/mandat-section.tsx`.

**Spec:** `docs/superpowers/specs/2026-10-03-statuts-design.md`

## Global Constraints

- Les statuts ne s'appliquent qu'aux formes à personne morale : `EURL`,
  `SASU`, `SARL`, `SAS`. Refusé côté backend pour `micro-entreprise`/`EI`,
  pas seulement caché côté frontend.
- `confirmed_legal_form` accepte les six formes de Former
  (`micro-entreprise`, `EI`, `EURL`, `SASU`, `SARL`, `SAS`), même si seules
  quatre déclenchent le générateur de statuts.
- **Aucun septième générateur** : `GENERATOR_NAMES`
  (`src/igini/usage/generator-names.ts`) est une liste fermée et
  délibérément protégée (« LES SIX GÉNÉRATEURS, NOMMÉS UNE SEULE FOIS »,
  reprise par le catalogue des offres). La génération de statuts est
  attribuée à `generator: 'former'` dans `AiUsageContext` — c'est
  conceptuellement la suite de la recommandation de forme juridique, pas un
  générateur à part. Ne jamais ajouter `'statuts'` à cette liste.
- Un seul appel à Claude par génération/régénération — pas d'aller-retour
  conversationnel, même principe que Former.
- Toute persistance de contenu généré par IGINI passe par
  `ConstitutionService.guard({ kind: 'persist_generated', ... })` — même
  convention que `ProjectsService` pour `analyses`/`legal_form_recommendations`
  (article 9 de la Constitution : « pas de données inventées » sans
  attribution correcte).
- Les parts des associés sont stockées en points de base (`share_basis_points`,
  entier), pas en pourcentage décimal — convention déjà établie ailleurs
  dans ce schéma (`equity_events.share_basis_points`). Affichage via le
  helper existant `pourcentage()` (`frontend/src/lib/montants.ts`).
- Les montants sont stockés en centimes entiers (`capital_cents`), jamais en
  flottant — convention déjà établie partout dans ce projet. Conversion via
  `centimesDepuisEuros()`/`euros()` (`frontend/src/lib/montants.ts`).
- Une version `retenue` est verrouillée : toute tentative d'édition, de
  régénération ou de nouvelle « rétention » est refusée explicitement
  (`ConflictException`), jamais silencieusement ignorée.

## Review Focus

- Tentative de générer des statuts pour un projet dont `confirmed_legal_form`
  est `micro-entreprise`/`EI` ou `null` → une personne raisonnable attend un
  refus explicite et compréhensible, pas une erreur 500 ni un document
  généré pour une forme qui n'a pas de personne morale. Testé en Task 3.
- Somme des parts des associés ≠ 100 % → doit être refusée **avant** l'appel
  Claude (qui coûte réellement de l'argent), pas après. Testé en Task 3.
- Tentative d'éditer, régénérer ou retenir une version déjà `retenue` →
  refusé explicitement (Conflict), jamais un écrasement silencieux d'un
  document qui a pu déjà servir de base à un dépôt. Testé en Task 4 et 5.
- Capital à zéro ou négatif → refusé avant l'appel Claude, avec un message
  clair plutôt qu'un document généré sur une base absurde. Testé en Task 3.
- Accès (lecture, édition, PDF) à des statuts d'un projet qui n'appartient
  pas à l'appelant → `NotFoundException`, cohérent avec la convention
  `findXForOwner` déjà utilisée partout ailleurs dans ce backend. Testé en
  Task 3 et 6.

```typescript
import { BadRequestException, Injectable, NotFoundException } from '@nestjs/common';
import { ConstitutionService } from '../constitution/constitution.service.js';
import { CLAUDE_MODEL, ClaudeService } from '../igini/claude/claude.service.js';
import { PrismaService } from '../prisma/prisma.service.js';
import { BYLAWS_SYSTEM_PROMPT, BylawsResultSchema } from './bylaws-prompt.js';
import type { GenerateBylawsDto } from './dto/statuts.dto.js';

/** Les quatre formes qui créent une personne morale distincte — voir la spec. */
const FORMES_AVEC_PERSONNE_MORALE = ['EURL', 'SASU', 'SARL', 'SAS'] as const;

/**
 * STATUTS — le brouillon du document fondateur de l'entreprise.
 *
 * Attribué au générateur `former` (voir Global Constraints du plan) : ce
 * n'est pas un septième générateur, c'est la suite de la recommandation de
 * forme juridique.
 */
@Injectable()
export class StatutsService {
  constructor(
    private readonly prisma: PrismaService,
    private readonly claude: ClaudeService,
    private readonly constitution: ConstitutionService,
  ) {}

  async genererPourProjet(ownerId: string, projectId: string, dto: GenerateBylawsDto) {
    const project = await this.prisma.projects.findFirst({
      where: { id: projectId, owner_id: ownerId },
    });
    if (!project) {
      throw new NotFoundException('Projet introuvable.');
    }

    const forme = project.confirmed_legal_form;
    if (!forme || !FORMES_AVEC_PERSONNE_MORALE.includes(forme as (typeof FORMES_AVEC_PERSONNE_MORALE)[number])) {
      throw new BadRequestException(
        "Les statuts ne s'appliquent qu'aux formes à personne morale (EURL, SASU, SARL, SAS). " +
          'Confirme une de ces formes sur le projet avant de générer des statuts.',
      );
    }

    const totalBasisPoints = dto.associates.reduce((somme, a) => somme + a.shareBasisPoints, 0);
    if (totalBasisPoints !== 10000) {
      throw new BadRequestException(
        `La somme des parts des associés doit faire 100 % (10000 points de base) ; elle fait ${totalBasisPoints}.`,
      );
    }

    const userContent =
      `Projet : ${project.title}\n` +
      `Forme juridique : ${forme}\n` +
      `Capital social : ${(dto.capitalCents / 100).toFixed(2)} €\n` +
      `Siège social : ${dto.headOffice}\n` +
      `Durée de la société : ${dto.durationYears} ans\n` +
      `Associés :\n` +
      dto.associates.map((a) => `- ${a.fullName} : ${(a.shareBasisPoints / 100).toFixed(2)} %`).join('\n');

    const result = await this.claude.generateStructuredOutput({
      schema: BylawsResultSchema,
      system: BYLAWS_SYSTEM_PROMPT,
      userContent,
      logContext: 'Échec de la génération des statuts via Claude',
      userErrorMessage: 'La génération des statuts a échoué, réessaie dans un instant.',
      usage: { userId: ownerId, projectId, generator: 'former' },
    });

    await this.constitution.guard(
      { kind: 'persist_generated', entity: 'company_bylaws', generatedBy: 'igini', generatedModel: CLAUDE_MODEL },
      { userId: ownerId, projectId },
    );

    const champsCommuns = {
      legal_form: forme,
      capital_cents: dto.capitalCents,
      head_office: dto.headOffice,
      duration_years: dto.durationYears,
      content: result.content,
      status: 'brouillon' as const,
      generated_by: 'igini',
      generated_model: CLAUDE_MODEL,
    };

    // upsert, pas create : une régénération (Task 4) rappelle cette même
    // méthode, et `project_id` est @unique sur ce modèle (une ligne par
    // projet, pas un historique — voir la spec). Les associés sont
    // entièrement remplacés plutôt que fusionnés : une régénération peut
    // changer leur nombre, fusionner ligne à ligne n'aurait pas de sens.
    return this.prisma.company_bylaws.upsert({
      where: { project_id: projectId },
      create: {
        owner_id: ownerId,
        project_id: projectId,
        ...champsCommuns,
        associates: {
          create: dto.associates.map((a) => ({
            full_name: a.fullName,
            share_basis_points: a.shareBasisPoints,
          })),
        },
      },
      update: {
        ...champsCommuns,
        associates: {
          deleteMany: {},
          create: dto.associates.map((a) => ({
            full_name: a.fullName,
            share_basis_points: a.shareBasisPoints,
          })),
        },
      },
    });
  }
}
```

**Note pour l'implémenteur** : la vérification du total des parts se fait
**avant** l'appel à `generateStructuredOutput` — un appel Claude coûte
réellement de l'argent, il ne faut jamais le déclencher pour une requête
qu'on sait déjà invalide. C'est délibérément dans cet ordre dans le code
ci-dessus ; ne pas le réorganiser.

/**
 * Génère le PDF à la volée, jamais stocké : le texte en base reste la seule

 */
export function genererPdfStatuts(content: string): Promise<Buffer> {
  return new Promise((resolve, reject) => {
    const doc = new PDFDocument({ margin: 50 });
    const chunks: Buffer[] = [];

    doc.on('data', (chunk: Buffer) => chunks.push(chunk));
    doc.on('end', () => resolve(Buffer.concat(chunks)));
    doc.on('error', reject);

    doc.fontSize(12).text(content, { align: 'left' });
    doc.end();
  });
}

'use client';

import { useCallback, useEffect, useState } from 'react';
import { api, ApiError, type CompanyBylaws } from '@/lib/api';

const FORMES = ['micro-entreprise', 'EI', 'EURL', 'SASU', 'SARL', 'SAS'] as const;

 * STATUTS — brouillon à relire, jamais un document prêt à déposer sans

export function StatutsSection({
  token,
  projectId,
  confirmedLegalForm,
  onFormConfirmed,

  token: string;
  projectId: string;
  confirmedLegalForm: string | null;
  onFormConfirmed: (form: string) => void;

  const [formeChoisie, setFormeChoisie] = useState(confirmedLegalForm ?? 'micro-entreprise');
  const [bylaws, setBylaws] = useState<CompanyBylaws | null>(null);
  const [isLoading, setIsLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  const [capital, setCapital] = useState('');
  const [headOffice, setHeadOffice] = useState('');
  const [durationYears, setDurationYears] = useState('99');
  const [associes, setAssocies] = useState<AssocieSaisie[]>([{ fullName: '', sharePercent: '100' }]);
  const [isGenerating, setIsGenerating] = useState(false);

  const aPersonneMorale = confirmedLegalForm ? FORMES_AVEC_PERSONNE_MORALE.has(confirmedLegalForm) : false;

      setIsLoading(false);
      return;

      setIsLoading(false);

    void charger();

      await api.confirmerFormeJuridique(token, projectId, formeChoisie);

          shareBasisPoints: Math.round(Number(a.sharePercent.replace(',', '.')) * 100),
        })),

      setBylaws(await api.genererStatuts(token, projectId, dto));
    } catch (err) {
      setError(err instanceof ApiError ? err.message : 'La génération a échoué.');
    } finally {
      setIsGenerating(false);
    }
  };

  if (isLoading) return null;

  return (
    <div className="card">
      <h2>Statuts</h2>
      {error && <p className="error">{error}</p>}

            <select value={formeChoisie} onChange={(e) => setFormeChoisie(e.target.value)}>
              {FORMES.map((f) => (
                <option key={f} value={f}>
                  {f}
                </option>
              ))}
            </select>
          </label>
          <button className="primary" type="button" onClick={confirmerForme}>
            Confirmer cette forme
          </button>
        </>
      )}

      {confirmedLegalForm && !aPersonneMorale && (
        <p className="muted">
          La micro-entreprise et l&apos;EI n&apos;ont pas de personne morale distincte à constituer :
          il n&apos;y a pas de statuts à générer pour cette forme.
        </p>
      )}

      {confirmedLegalForm && aPersonneMorale && !bylaws && (
        <>
          <p className="notice">
            Ce qui suit est un brouillon à relire — jamais un document prêt à déposer sans contrôle.
          </p>
          <label>
            Capital social (€)
            <input value={capital} onChange={(e) => setCapital(e.target.value)} aria-label="Capital social (€)" />
          </label>
          <label>
            Siège social
            <input value={headOffice} onChange={(e) => setHeadOffice(e.target.value)} />
          </label>
          <label>
            Durée de la société (années)
            <input value={durationYears} onChange={(e) => setDurationYears(e.target.value)} />
          </label>
          {associes.map((associe, index) => (
            <div key={index}>
              <label>
                Nom de l&apos;associé
                <input
                  value={associe.fullName}
                  onChange={(e) => {
                    const copie = [...associes];
                    copie[index] = { ...copie[index], fullName: e.target.value };

                  }}
                />
              </label>
              <label>
                Part (%)

                  onChange={(e) => {
                    const copie = [...associes];
                    copie[index] = { ...copie[index], sharePercent: e.target.value };
                    setAssocies(copie);
                  }}
                />
              </label>
            </div>
          ))}
          <button type="button" onClick={() => setAssocies([...associes, { fullName: '', sharePercent: '' }])}>
            Ajouter un associé
          </button>
          <button className="primary" type="button" onClick={genererStatuts} disabled={isGenerating}>
            {isGenerating ? 'Génération…' : 'Générer les statuts'}
          </button>
        </>
      )}
    </div>
  );
}
